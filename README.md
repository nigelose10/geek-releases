# Geek releases

Installers and update channels for **Geek**, the desktop app for York University students: a school dashboard, course bots with shared memory, and a glass overlay one hotkey away.

**No releases yet.** The first signed builds are targeted for late November 2026:

| Asset | For |
|---|---|
| `Geek-mac-arm64.dmg` | Mac with Apple silicon, macOS 13 or later |
| `Geek-mac-x64.dmg` | Intel Mac, macOS 13 or later |
| `Geek-win-x64.exe` | Windows 11 (x64) |

## Get notified

Click **Watch**, then **Custom**, tick **Releases**, then **Apply**. GitHub emails you when a build ships.

## Channels

- **Stable**: normal releases. The app updates itself.
- **Beta**: pre-releases, turned on in Geek's settings.

Every release will list SHA-256 checksums. Installers are only ever published here, never sent as attachments.
